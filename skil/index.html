Паперовий колаж-рілс з Claude

Скіл для Claude Code. Він допомагає зробити вертикальне відео у стилі паперового колажу з твоєю історією, твоїм голосом і твоїми фото. Вирізання й збірка відео відбуваються на твоєму комп'ютері.

Завантажити скіл (zip, 1 МБ)
Ти з телефона? Скіл ставиться на комп'ютер. Скопіюй посилання, відкрий його на комп'ютері й завантаж там. У Instagram завантаження зазвичай не працює: натисни ⋯ і «Відкрити в браузері».

Що потрібно

  • Claude Code на комп'ютері і платна підписка Claude.
  • ffmpeg: Claude підкаже, як його поставити.
  • Для macOS і Windows. Якщо щось не спрацює, віддай помилку Claude: він виправить.
  • Сценарій (або пишете разом із Claude), свій голос і свої фото. Стікерів і картинок у скілі нема, але Claude може знайти безкоштовні в інтернеті (завантажить лише після твого «так»), або дай свої.

Як почати

  1. Розпакуй zip. Папку paper-collage-reel поклади в ~/.claude/skills/ (на Windows: %USERPROFILE%\.claude\skills\).
  2. Відкрий Claude Code і напиши:
    налаштуй paper-collage-reel
  3. Коли побачиш SMOKE TEST OK, скіл готовий. Далі напиши:
    зроби мені collage reel
  4. Claude ставитиме питання по черзі: про що рілс, голос, фото. Ти затверджуєш чотири етапи: розкладку, вирізки, рух і готове відео.

Перший раз моделі завантажуються самі (вирізання фону, розпізнавання мови), це одноразово. Детальніше в файлі README-UA.md усередині архіву.
